# Digital Systems Design & Computer Architecture (AUEB)

Projects developed for the Digital Systems Design course at the Athens University of Economics and Business (AUEB).

## Projects Overview
1. **[01. Combinational Logic Circuits](./01-combinational-logic)**: Implementation and functional verification of a 5-variable logic function using both behavioral/structural VHDL and Schematic design.
2. **[02. 16-bit Hierarchical ALU](./02-16bit-hierarchical-alu)**: Design, hierarchical composition, and verification of a 16-bit Arithmetic Logic Unit built from modular 1-bit ALU slices.

## Tools Used
- **Intel Quartus Prime Lite Edition** (Synthesis, Fitting, Timing Analysis)
- **ModelSim / University Program VWF** (Functional & Timing Simulation)
